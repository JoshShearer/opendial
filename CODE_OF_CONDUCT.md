# Code of conduct

OpenDial follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good intent, and keep discussion
about the work. Harassment, insults and personal attacks are not tolerated.

To report a problem, contact the maintainer privately through the
[security advisory form](https://github.com/JoshShearer/opendial/security/advisories/new)
or by GitHub message to @JoshShearer. Reports are kept confidential.
